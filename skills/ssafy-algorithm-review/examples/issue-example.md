# 숫자 만들기

주어진 숫자 순서를 유지하면서 연산자를 배치해 가능한 결과의 최댓값과 최솟값 차이를 구하는 문제이다.

## [제약 사항]

- `3 ≤ N ≤ 12`
- 연산자 개수 합은 `N - 1`

## 접근 방법

연산자별 남은 개수를 상태로 두고 DFS/백트래킹으로 모든 배치를 탐색한다.

## 핵심 구현

```java
operators[i]--;
calculate(index + 1, next);
operators[i]++;
```

## 복잡도

연산자 배치 경우의 수에 비례.

## 다른 아이디어

연산자 배열 순열을 만들 수도 있으나 중복 연산자 처리 측면에서 개수 기반 백트래킹이 더 자연스럽다.
```
