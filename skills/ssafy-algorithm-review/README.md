# SSAFY Algorithm Review Skill

Reusable workflow for reviewing daily Java algorithm commits in `YEOUL0520/STUDYWITHSSAFY_16` and generating consistent GitHub Issue/PR text.

## Structure

```text
skills/ssafy-algorithm-review/
├── SKILL.md
├── README.md
└── examples/
    ├── issue-example.md
    └── pr-example.md
```

## Typical prompts

- `0907 변경 사항 확인 및 PR, 이슈 텍스트 생성해줘`
- `0904 커밋 확인하고 PR, issue 텍스트 작성해줘`
- `wh 브랜치에서 오늘 추가한 문제들 이슈로 정리해줘`
- `0903 누락된 이슈 확인해줘`

## Storage

이 스킬은 GitHub에서 버전 관리하며, `SKILL.md`와 예시 리소스를 함께 보관합니다.
